What does Kerbside Scorecard do?

Kerbside Scorecard is a working tool built to work for any local business. The tool I use to show a business owner where their Google listing is leaking — with the marking scheme on the table, not hidden.

It sits in the Broad lane: works for any service business: booking, quotes, the pipeline, follow-up, reviews.

What is in it

  • A visible rubric with per-row deductions
  • Re-marks live as numbers change
  • Competitor comparison table
  • Prints as a client-ready report

How it was builtBy hand, with nothing bought in
Written
By hand, as a single self-contained page. No page-builder, no theme, no framework.
Dependencies
None at runtime. Fonts load from Google Fonts with system fallbacks; everything else — every drawing, chart and interaction — is in the file.
Imagery
No stock. Every visual is drawn in code, SVG or canvas.
The business
Google profile report card — invented. Every person, number and review inside is fictional so nothing here exposes a real client.
Runs on
Any modern browser. It is designed for a desktop or tablet; on a phone, open it full screen. State stays in your browser; there is a reset control inside.
