What does Halcyon Dispatch do?

Halcyon Dispatch is a working tool built for an invented heating dispatch. The morning phone round — "where are you, can you take one more" — replaced by a board that already knows.

It sits in the Broad lane: works for any service business: booking, quotes, the pipeline, follow-up, reviews.

What is in it

  • Week and day views for a whole team
  • Drag-and-drop rescheduling with clash and capacity warnings
  • SLA countdowns and an emergency queue
  • Statuses derived from the real clock, so the board is never stale

How it was builtBy hand, with nothing bought in
Written
By hand, as a single self-contained page. No page-builder, no theme, no framework.
Dependencies
None at runtime. Fonts load from Google Fonts with system fallbacks; everything else — every drawing, chart and interaction — is in the file.
Imagery
No stock. Every visual is drawn in code, SVG or canvas.
The business
Heating dispatch team — invented. Every person, number and review inside is fictional so nothing here exposes a real client.
Runs on
Any modern browser. It is designed for a desktop or tablet; on a phone, open it full screen. State stays in your browser; there is a reset control inside.
Yours would
